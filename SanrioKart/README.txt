Sanrio Kart（iPad向けWebゲーム）

起動方法
1. このフォルダをWebサーバーに置き、Safariで index.html を開きます。
2. iPadを横向きにし、「レーススタート」を押します。
3. モーションと方向へのアクセスを求められた場合は「許可」してください。
4. 今の持ち方で直進しにくい場合は「中央調整」を押します。

操作
- iPad：左右に傾ける
- 画面：左右下の矢印ボタン
- PC：← / → または A / D
- アクセルは自動、ブレーキはありません。
- 視点は車の後方から前方を見る、三人称ドライバー視点です。
- 舗装路から草地へ出ると大きく減速します。ブースト中も草地では舗装路より遅くなります。
- クロミに当たるとスピンして停止し、復帰してから1秒間は無敵になります。

キャラクター画像
assets フォルダに次の画像を置くと、自動でゲームに反映されます。
- 01-pompompurin.png
- 02-cinnamon.png
- 04-kuromi.png
- 07-mymelody.png

画像がない場合も、色付きの代替アイコンでゲームは最後まで遊べます。

ホーム画面に追加
Safariの共有ボタンから「ホーム画面に追加」を選ぶと、横画面のアプリとして起動できます。
